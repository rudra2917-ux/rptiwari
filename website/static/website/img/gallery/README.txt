Put real photos of your flour mills, plants, machinery and site visits in this folder
(.jpg, .jpeg, .png, .webp). They appear automatically in the "Gallery" section on the
Home and About pages. No code change is needed.

The file name becomes the caption, e.g.
    buhler-rollermill-floor-cuttack.jpg  ->  "Buhler rollermill floor cuttack"

Tip: resize photos to around 1200px wide so the site stays fast.
